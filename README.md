# 🛠️ TechSupport – Technical Support Helpdesk System

TechSupport is a web-based Technical Support Helpdesk System designed to manage customer support requests in an organized and user-friendly way.

The system allows customers to raise support tickets and communicate with support agents, while agents can manage and resolve tickets. Administrators can monitor and manage the complete support system.

---

## 📌 Project Overview

The main purpose of TechSupport is to create a simple platform for handling technical support requests.

The system provides different features according to the user's role:

- Customer
- Agent
- Admin

Each role has different access and responsibilities within the system.

---

## 👥 User Roles

### 👤 Customer

Customers can:

- Access their dashboard
- View their profile
- Raise/Create support tickets
- View their tickets
- Communicate through Live Chat
- Give feedback and ratings

### 🧑‍💻 Agent

Agents can:

- Access the support dashboard
- View customer tickets
- Manage ticket status
- Communicate with customers through Live Chat
- Access the Knowledge Base
- View customer information

### 👑 Admin

Administrators have access to the complete system.

Admin can:

- Monitor the dashboard
- Manage tickets
- View customers
- Manage agents
- Monitor Live Chat
- View Analytics
- View Feedback
- Generate Reports
- Access the Knowledge Base
